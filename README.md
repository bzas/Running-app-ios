# Renn - Running
Aplicación iOS (SwiftUI) para registrar y visualizar sesiones de running. Este proyecto está en una fase inicial y actualmente muestra una vista básica de prueba.

## Características
- Registro de carreras: distancia, tiempo, ritmo medio, calorías.
- Integración con HealthKit y otras plataformas para leer datos de actividad física.
- Mapa del recorrido (MapKit) y trazado de ruta en tiempo real.
- Historial de entrenamientos y detalles por sesión.
- Gráficas (ritmo, frecuencia cardiaca, elevación).
- Objetivos, records personales y streaks.
- Widgets y Live Activities (Dynamic Island/Lock Screen).
- Sincronización y copia de seguridad (iCloud/CloudKit).

## Requisitos
- Xcode 15 o superior (recomendado Xcode 16/26.1 según tu entorno).
- iOS 17 o superior (ajusta la versión de destino según tus necesidades).
- Swift 6 o superior.
